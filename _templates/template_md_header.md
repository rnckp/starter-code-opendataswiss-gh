The Notebooks column links to **Colab**, **Python** and **R**. Datasets with multiple CSV files show resource labels beneath their names to distinguish the notebooks. To download a source file from GitHub, open its `RAW` view and save that file. Check the inferred CSV separator and column types before analyzing the data.
